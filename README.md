# Peer42

A premium Flutter mobile application for 42 Network students.

## Features
- **Real-time Profile:** View user levels, wallet, evaluation points, and active locations.
- **Project Tracking:** Advanced hierarchical project list with Cursus-based filtering (Core, Piscine, etc.).
- **Visual RPG Elements:** Dynamic level progress bars and coalition-themed aesthetics.
- **Search:** Instant student search with recent history.

## Getting Started
1. Clone the repository.
2. Setup your 42 API credentials.
3. Run `flutter pub get`.
4. Run `flutter run`.

## Tech Stack
- Flutter & Dart
- Provider for state management
- Dio for API requests
- Google Fonts (Lilita One, Hanken Grotesk)
